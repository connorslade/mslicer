# Contributing

## Code Contributions

Pull requests are welcome, but please consider [reaching out](https://mslicer.zulipchat.com) or making a GitHub issue first for discussion, especially if you are making big changes.
I don't want you to waste effort on a PR that won't get merged!

In addition to the active issues, the [notes.md](notes.md) file lists bugs that need fixing and planned features.
If you would like to help out but don't know what to work on, this is a good place to start.

## AI Policy

Generating code for mslicer using an LLM is discouraged.
Large chunks of AI-generated code are often not up to the project's code quality standard and may prevent your contribution from being merged.
However, LLMs can be helpful for asking questions about the codebase.
