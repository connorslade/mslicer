# `remote_print`

Library / tool for remote control of ChiTu-mainboard resin printers.

Thank you to [Vladimir Vukicevic](https://github.com/vvuk) for figuring all of the V1.0.0 protocol communication stuff out, find his writeup and implementation of the protocol [here](https://github.com/vvuk/cassini).

The V3.0.0 protocol is officially documented [here](https://github.com/cbd-tech/SDCP-Smart-Device-Control-Protocol-V3.0.0/), but the [elegoo-homeassistant](https://github.com/danielcherubini/elegoo-homeassistant) project was a helpful reference.
